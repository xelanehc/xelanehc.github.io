# Project notes

Personal site for Alex Chen, statically exported to GitHub Pages. See README.md for structure, scripts, and content editing. If `docs/STEERING.md` exists locally (it's git-ignored), it holds the redesign plan, decisions, and phase log.

## Rules

- Never commit or link a resume, and never show a phone number on the site.
- Content lives in `src/content/` (typed by `src/types/content.ts`); don't hardcode content in components.
- `src/components/ui/` is generated by the shadcn CLI. Wrap, don't edit.
- Use `m.*` from `motion/react-m` (LazyMotion strict mode); `motion.*` throws.
- Image/metadata routes must be `force-static` with a real file extension.
- Run `npm run check && npm run build` before calling work done. For UI changes, also check both themes, 390px width, and reduced motion.
